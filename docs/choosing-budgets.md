# Как выбрать бюджеты

1. **Начните с факта.** Соберите проект и посмотрите `size-report.json`. Первые лимиты — текущий размер плюс 5–10%: сборка не падает сегодня, но рост станет заметен.
2. **Главный бюджет — `@initial`.** Это то, что пользователь скачивает до первого экрана. Ориентиры для мобильного 4G: ≤ 170 kB JS (brotli) для приложений, ≤ 100 kB для лендингов.
3. **Ограничьте рост, а не только потолок.** `maxIncrease: '3%'` ловит постепенное раздувание, которое никогда не упирается в лимит.
4. **Отдельно — ленивые чанки.** `@lazy` с `maxFile` не даёт одной странице утащить половину бандла.
5. **Шрифты и картинки** уже сжаты; для них используйте `compression: 'none'`.
6. **Пересматривайте раз в квартал.** Удалили зависимость — опустите лимит, чтобы экономия не «съелась» обратно.
