# Как считается `@initial`

Плагин проходит граф чанков Rollup:

1. Берёт все entry-чанки (`isEntry`).
2. Рекурсивно добавляет их **статические** импорты (`chunk.imports`).
3. Добавляет CSS, который Vite привязал к этим чанкам (`viteMetadata.importedCss`).

Чанки, доступные только через `import()` (`chunk.dynamicImports`), не входят в `@initial`, они попадают в `@lazy`. Это совпадает с тем, что браузер загружает до выполнения entry: Vite добавляет `modulepreload` именно для статических зависимостей.

Ограничения: файлы из `public/` и ресурсы, на которые ссылается только HTML (например, favicon), в граф не попадают. Для них используйте обычные glob-бюджеты.
